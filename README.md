# 🌍 Study MBBS Abroad - Responsive Landing Page

This project is a **responsive landing page** designed for **University Insights**, promoting MBBS programs abroad. It features key benefits, top destinations, an admission guide, and a **lead generation form** for student inquiries.

## 🚀 Features

- **Hero Section** 📢: Engaging banner with a CTA ("Apply Now for MBBS Abroad").
- **Why Study MBBS Abroad** ✅: Highlights the advantages of studying medicine overseas.
- **Top Countries** 🌎: Showcases popular destinations (Russia, Uzbekistan, Kazakhstan, Philippines, Georgia, Kyrgyzstan, Egypt).
- **Admission Process & Eligibility** 🏫: Step-by-step guide for applicants.
- **Lead Generation Form** 📩: Captures user details (name, email, phone, country preference).
- **Fully Responsive** 📱: Optimized for mobile, tablet, and desktop.
- **SEO Optimized** 🔍: Clean HTML structure and meta tags for better ranking.
- **Performance Tracking** 📊: Integrated Google Analytics & Facebook Pixel.

## 🛠️ Tech Stack

- **HTML, CSS (TailwindCSS)** 🎨: Modern and responsive design.
- **JavaScript** ✨: Enhances interactivity and form validation.
- **Netlify/Vercel** 🌐: Live hosting for easy access.
